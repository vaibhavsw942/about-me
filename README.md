# Vaibhav Suryawanshi - Portfolio

Personal portfolio built with React, Vite and Tailwind CSS.

## Run locally
```bash
npm install --legacy-peer-deps
npm run dev
```

## Where to edit
- `src/data/portfolioData.js` - projects, certificates, skills
- `src/Pages/Home.jsx` - hero text, typing roles
- `src/Pages/About.jsx` - about text, stats
- `src/components/SocialLinks.jsx` - contact links
- `public/Photo.png` - profile photo, `public/Vaibhav_Suryawanshi_Resume.pdf` - CV
- `index.html` - page title and SEO
